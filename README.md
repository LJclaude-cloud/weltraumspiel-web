# Mondmission – Web-Version

Spielbare Web-Version des Spiels „Mondmission“ (Godot 4.7, für die NASA Space Apps Challenge 2026).
Dieses Repo enthält nur den fertigen Web-Export, nicht den Quellcode.

**Spielen:** https://ljclaude-cloud.github.io/weltraumspiel-web/

- Am PC: WASD laufen, Leertaste springen, E benutzen, ins Bild klicken zum Umschauen
- Auf iPad/Handy: quer halten, links Joystick, rechts wischen zum Umschauen
- Empfindlichkeit beim Umschauen: Knopf „Einstellungen“

Gebaut ohne Thread-Support, läuft daher auch ohne besondere Server-Header (z. B. auf GitHub Pages).
Verwendete 3D-Modelle und ihre Lizenzen: siehe [LIZENZEN.md](LIZENZEN.md).
